# Security

Poker is a play-chips-only game. Nothing in it handles money, payments, or
accounts, so the main things worth reporting are server crashes, ways to see
another seat's cards or the deck, and ways to make the public server expensive
to run.

## Reporting a problem

Please report privately through GitHub's
[security advisory form](https://github.com/Amishkakru/poker/security/advisories/new)
rather than opening a public issue. Include the version or commit, what you
did, and what happened. You can expect an initial reply within a week.

## Supported versions

The `main` branch is the supported version. Deployments are expected to run a
single instance; see "Put it online" in the README.
